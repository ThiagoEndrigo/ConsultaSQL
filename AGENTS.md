# Instruções para o projeto ConsultaSQL

## Publicação no GitHub exige autorização explícita

- Não envie código ou executáveis ao GitHub sem autorização explícita do usuário na conversa atual.
- Isso inclui `git push`, envio de tags, criação/publicação de releases e qualquer ação que publique uma nova versão.
- Uma autorização dada anteriormente para publicar uma versão não vale para versões futuras.
- É permitido preparar e compilar alterações localmente. Ao terminar, informe o que está pronto e aguarde autorização antes de publicar.
